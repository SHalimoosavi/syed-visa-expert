## 🚀 Installation & Setup

### Option 1: GitHub Pages

1. **Create GitHub Repository**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: SAYANJALI NEXUS website"
   git remote add origin https://github.com/username/sayedalihasanmoosavi.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Select "main" branch as source
   - Custom domain: sayedalihasanmoosavi.com

3. **DNS Configuration**
   - Add CNAME record: sayedalihasanmoosavi.com → username.github.io

### Option 2: Netlify

1. **Connect Repository**
   - Go to netlify.com
   - Connect GitHub repository
   - Build command: (leave empty - static site)

2. **Domain Setup**
   - Add custom domain in Netlify dashboard
   - Update DNS records

### Option 3: Vercel

1. **Deploy**
   ```bash
   npm i -g vercel
   vercel
   ```

2. **Configure Domain**
   - Add custom domain in Vercel dashboard

### Option 4: Self-Hosted

1. **Upload Files**
   - Upload all files to web host
   - Ensure index.html is in root directory

2. **Configure Server**
   - Set proper MIME types
   - Enable gzip compression
   - Configure caching headers
