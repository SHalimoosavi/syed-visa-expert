## 🔧 CUSTOMIZATION GUIDE

### Change Primary Color
Find and replace in CSS:
```css
--color-electric-blue: #00d9ff;
--color-cyan: #00f7ff;
```

### Change Fonts
Replace Google Fonts link:
```html
<link href="https://fonts.googleapis.com/css2?family=YOUR-FONT&display=swap">
```

### Modify Spacing
Update CSS variables:
```css
--spacing-unit: 4px;
--gap-sm: 16px;
--gap-md: 30px;
--gap-lg: 60px;
```

### Add Sections
Copy section template:
```html
<section class="section-name">
    <div class="container">
        <div class="section-header">
            <h2>Title</h2>
            <p>Description</p>
        </div>
        <!-- Content -->
    </div>
</section>
```
