## TROUBLESHOOTING COMMON ISSUES

### Issue 1: FAQ Not Showing in SERP
**Solution:**
- Verify schema at: https://schema.org/validate/
- Ensure questions are common user queries
- Check Google Search Console for errors
- Wait 2-4 weeks for Google to index
- Use Search Console "Request Indexing"

### Issue 2: Local Knowledge Panel Not Showing
**Solution:**
- Complete LocalBusiness schema
- Ensure address is specific
- Add business hours if available
- Get Google verified badge
- Consistent NAP (Name, Address, Phone)

### Issue 3: Mobile Rendering Issues
**Solution:**
- Test: https://search.google.com/test/mobile-friendly
- Check viewport meta tag
- Fix CSS/JavaScript for mobile
- Test on actual devices
- Check Core Web Vitals

### Issue 4: Rankings Not Improving
**Solution:**
- Wait 6-8 weeks for indexing
- Build high-quality backlinks
- Create more internal links
- Expand content volume
- Improve user engagement signals
- Check competitor strategies

### Issue 5: CTR Still Low
**Solution:**
- Improve meta description appeal
- Add numbers/power words
- Create urgency in title
- A/B test different descriptions
- Ensure snippet shows key info
- Check actual vs expected CTR
